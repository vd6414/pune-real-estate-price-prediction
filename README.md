# pune-real-estate-price-prediction
AI-powered real estate price prediction system using Machine Learning and Linear Regression.

## Overview

This project is a Machine Learning-based housing price prediction system developed using Python and Linear Regression. The model predicts residential property prices in Pune using important real estate features such as location, BHK, carpet area, floor number, parking spaces, amenities, and building age.

The main goal of this project is to analyze housing market data and build an intelligent system capable of estimating accurate property prices.
